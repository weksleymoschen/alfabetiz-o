# Monta-Palavras

Jogo de alfabetização com 20 imagens, montagem de letras e sílabas, áudio, nome do estudante e comemorações.

## Publicar no GitHub Pages

1. Crie um repositório exclusivo para este jogo.
2. Extraia este ZIP no computador.
3. No repositório, escolha **Add file → Upload files** e envie `index.html`, `.nojekyll` e `README.md` à raiz do repositório. Não envie apenas o ZIP.
4. Clique em **Commit changes**.
5. Abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.
8. Quando a publicação terminar, abra o endereço exibido em **Pages**.

## Uso

Abra o endereço no Chrome, digite o nome do estudante e clique em COMEÇAR. O jogo começa no modo letras; o botão MONTAR SÍLABAS permite mudar o modo. Arraste as peças ou clique na peça e depois no quadrinho.

As imagens e o fundo estão incorporados ao HTML. A narração usa as vozes disponíveis no navegador e no sistema; a disponibilidade de voz sem internet depende do dispositivo. O nome do estudante é usado somente na sessão do jogo, sem envio a um servidor.

## Atualizar

Substitua `index.html` no mesmo repositório e confirme a alteração. O GitHub Pages publicará a nova versão.
